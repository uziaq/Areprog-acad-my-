## Objectif

Découper en blocs un schéma public complet, suivre ses réseaux et ses masses, puis relever le
brochage d'un connecteur sur le schéma électrique officiel du constructeur d'un véhicule d'atelier.

## Matériel

- Le schéma public de l'Arduino UNO Rev3, imprimé en grand format [SOURCÉ : SRC-0032 §page 1], et des crayons de couleur.
- Si l'atelier en dispose, une carte compatible avec ce schéma, non alimentée, pour situer les blocs [À VÉRIFIER : carte disponible à l'atelier et conformité de sa révision au schéma].
- Les fiches techniques des composants principaux du schéma [À VÉRIFIER : fiches à télécharger chez leurs fabricants].
- La documentation électrique officielle du constructeur d'un véhicule d'atelier désigné par son code interne, par exemple VEH-01 [À VÉRIFIER : accès à la documentation officielle du constructeur pour les véhicules de l'atelier].

## Sécurité

- Aucune mise sous tension dans ce TP : la carte reste débranchée, sans câble USB ni alimentation.
- Carte manipulée sur le poste ESD, bracelet relié (FE-01 ; S01-L01).
- Partie B sur document uniquement : aucune intervention sur le véhicule dans ce TP.

## Schéma de câblage

Aucun câblage. Le schéma support est le document public de la partie A ; la partie B se fait sur la
documentation officielle du constructeur.

## Procédure

**Partie A : schéma public**

1. Lister les symboles du schéma et nommer chacun ; marquer `[À VÉRIFIER]` ceux qu'on ne reconnaît pas, puis chercher la fiche du composant.
2. Repérer les nœuds d'alimentation et de masse ; écrire la liste des noms (par exemple GND, AGND, UGND [SOURCÉ : SRC-0032 §page 1]) et chercher où les masses se rejoignent.
3. Repérer le composant principal ; lire dans sa fiche ses broches d'alimentation et d'horloge.
4. Encadrer chaque bloc d'une couleur ; écrire son nom et la liste de ses références dans le tableau.
5. Choisir une étiquette de réseau ; suivre toutes ses apparitions et lister les composants qu'elle touche.
6. Si une carte est disponible, situer chaque bloc sur la carte hors tension ; photographier.

**Partie B : schéma électrique constructeur**

7. Ouvrir la documentation officielle ; noter son titre, sa version et le code interne du véhicule.
8. Choisir le connecteur d'un capteur ; lire la légende (vue côté faisceau ou côté composant, abréviations des couleurs).
9. Relever chaque broche : numéro, fonction, couleur du fil, destination ; marquer `[À VÉRIFIER]` toute ligne qui n'est pas lue sur le document.

## Relevés

| Mesure | Valeur attendue | Valeur relevée | Commentaire |
|---|---|---|---|
| Nombre de blocs encadrés | six blocs au moins, ou justification d'un bloc absent [EXEMPLE : découpage pédagogique] | | |
| Masses du schéma public | liste des noms et point de liaison [SOURCÉ : SRC-0032 §page 1] | | |
| Réseau suivi | toutes ses apparitions et tous les composants touchés | | |
| Brochage du connecteur | lu sur le document officiel [À VÉRIFIER : selon le véhicule et le connecteur choisis] | | |

## Tolérance justifiée

- Découpage : plusieurs découpages sont acceptables si chaque bloc est justifié par sa fonction et ses références [SOURCÉ : SRC-0030 §Identify Blocks].
- Masses : une liaison entre masses non trouvée sur le schéma reste `[À VÉRIFIER]`, jamais supposée.
- Brochage : aucune tolérance ; chaque ligne est lue sur le document officiel ou marquée `[À VÉRIFIER]`.

## Livrable et preuves

Schéma annoté (photo ou scan), tableau des références par bloc, liste des masses, réseau suivi,
brochage relevé avec la référence du document. Un critère sans preuve vaut 0.
