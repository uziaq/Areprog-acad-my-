# Sécurité et déploiement

- **Aucun déploiement** (Netlify ou autre) sans l'accord écrit d'Arthur dans la conversation en cours. Ne pas relier le dépôt à un site Netlify, ne pas activer les aperçus de PR.
- Avant le premier déploiement autorisé : protection par mot de passe (décision A-04), en-tête `noindex` conservé.
- Aucun secret dans le dépôt : variables d'environnement Netlify uniquement.
- Aucun document sous licence restrictive (normes, datasheets propriétaires) dans `public/` ou `content/`.
- Le protocole renforcé airbag / ABS / direction et les TP sur véhicule sont imposés par le code : verrou sans dérogation, check-list avec preuves, critère éliminatoire. Ne jamais ajouter de contournement, même pour un test manuel.
